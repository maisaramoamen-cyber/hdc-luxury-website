## Development Commands
```bash
npm install              # Install dependencies
npm run build           # Build psychology-enhanced website
npm run dev            # Start development with color optimization
npm run deploy         # Deploy to Cloudflare Pages
pm2 start ecosystem.config.cjs  # Launch with PM2
```

## Deployment Instructions
1. **Install Dependencies**: `npm install`
2. **Build Project**: `npm run build`
3. **Deploy to Cloudflare**: `npm run deploy`
4. **Local Development**: Use PM2 with `pm2 start ecosystem.config.cjs`
